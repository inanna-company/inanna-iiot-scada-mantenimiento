📄 Vista Previa del Cliente Maestro Modbus TCP en Java (Incluido en InannaScadaDesktop.java):

// Trama MBAP + PDU Función 0x03 (Leer 10 Holding Registers desde 40001 en Puerto 502)
Socket socket = new Socket();
socket.connect(new InetSocketAddress("192.168.4.1", 502), 800);

byte[] req = new byte[] {
    0x00, 0x01, // Transaction ID
    0x00, 0x00, // Protocol ID (0 = Modbus)
    0x00, 0x06, // Length
    0x01,       // Unit ID 1 (Esclavo ESP32 INANNA)
    0x03,       // FC 0x03 Read Holding Registers
    0x00, 0x00, // Start Address 0 (40001)
    0x00, 0x0A  // Quantity: 10 Registros (40001..40010)
};
socket.getOutputStream().write(req);
